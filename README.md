# GIZ SWEETS

GIZ SWEETS, farklı tatlı çeşitlerinin yer aldığı ve kullanıcıların ürünleri inceleyebileceği bir tatlı web sitesi projesidir.

## Projede Neler Yaptım?

- HTML kullanarak web sitesinin temel yapısını oluşturdum.
- CSS kullanarak sayfanın tasarımını, renklerini ve düzenini hazırladım.
- Tatlı ürünlerini kullanıcıların kolayca inceleyebileceği şekilde listeledim.
- Ürün görsellerini ve içeriklerini sayfalara ekledim.
- Menü ve sayfa geçişlerini düzenledim.
- Kullanıcıların site içerisinde rahat gezinebileceği bir arayüz tasarladım.
- Web sitesinin farklı ekran boyutlarında düzgün görüntülenmesine dikkat ettim.

## Kullandığım Teknolojiler

- HTML5
- CSS3

## Proje Hakkında

Bu projeyi okul kapsamında web tasarım çalışması olarak hazırladım. Proje sürecinde HTML ve CSS kullanarak bir web sitesinin yapısını oluşturma, sayfa tasarımı ve kullanıcı arayüzü hazırlama üzerine çalışmalar yaptım.
